 # Predictive Coding

An experimental project exploring **predictive coding**: a theory of information processing in which a system continuously predicts incoming data and updates its internal representation using the resulting prediction error.

## Overview

The project is intended as a space for implementing and experimenting with predictive-coding models. A typical predictive-coding system consists of:

- **Hierarchical representations** that encode increasingly abstract features.
- **Top-down predictions** generated by higher-level representations.
- **Bottom-up prediction errors** measuring the difference between observations and predictions.
- **Iterative updates** that reduce prediction error over time.

Conceptually, the update cycle is:

```text
observation → prediction error → representation update → improved prediction
```

## Core concepts

### Prediction

Each layer estimates the activity of the layer below it. These estimates provide a top-down explanation of the observed input.

### Prediction error

The error signal is the difference between observed activity and the activity predicted by the model. Minimizing this error drives learning and inference.

### Hierarchical inference

Information flows in both directions: predictions move downward, while errors move upward. Repeated updates allow the hierarchy to converge on an explanation of the input.

## Experiments

Useful experiments include:

1. Comparing reconstruction quality with and without hierarchical inference.
2. Measuring convergence as the number of inference steps changes.
3. Testing robustness against noise and incomplete observations.
4. Visualizing predictions, errors, and learned representations at each layer.
